# 🔐 CS 4910: Cybersecurity Course Project Instructions

## 📋 Overview

The course project is a major component of CS 4910, designed to give you hands-on experience with cybersecurity concepts and tools. This project will allow you to apply the knowledge gained throughout the course to a real-world security challenge.

## 👥 Team Structure

- Work in teams of **two students**
- Both team members must contribute equally to all aspects of the project
- Each team will select a unique topic (first come, first served)

## 🎯 Project Requirements

1. **Topic Selection**: Choose a cybersecurity topic that interests your team
2. **Hands-on Component**: Your project must include practical, hands-on work
3. **Research**: Conduct thorough research on your chosen topic
4. **Implementation**: Create a practical demonstration of security concepts
5. **Analysis**: Analyze your findings and draw meaningful conclusions

## 📅 Project Timeline

| Milestone | Due Date | Description |
|-----------|----------|-------------|
| Topic Selection | Week 4 | Submit your project topic for approval |
| Project Proposal | Week 7 | Present your project plan to the class |
| Progress Check | Week 11 | Brief update on project progress |
| Final Presentation | Week 16 | Present your completed project |
| Demo Video & Report | 12/15 | Submit final deliverables |

## 📦 Required Deliverables

### 1. 📊 Final Presentation (PowerPoint)
- 10-12 minute presentation
- Cover project background, methodology, implementation, findings, and conclusions
- All team members must participate in the presentation
- [Use the provided PowerPoint template](/workspace/CS4910/project_templates/presentation_template.pptx)

### 2. 🎥 Demo Video
- 3-5 minute video demonstration of your project
- Show the practical implementation in action
- Explain key technical aspects
- Highlight security implications
- [See video creation guidelines below](#video-creation-guidelines)

### 3. 📄 Project Report
- 3-page report in IEEE conference proceedings format
- Follow the [IEEE template](https://www.ieee.org/conferences/publishing/templates.html)
- [Use the provided Word template](/workspace/CS4910/project_templates/report_template.docx)
- Additional content can be included in clearly marked appendices
- Proper citations required for all external resources

## 📝 Report Structure

Your 3-page IEEE-formatted report should include:

1. **Abstract**: Brief summary of the project (150-200 words)
2. **Introduction**: Background, motivation, and project objectives
3. **Related Work**: Brief overview of existing research/solutions
4. **Methodology**: Approach, tools, and techniques used
5. **Implementation**: Details of your practical implementation
6. **Results & Analysis**: Findings and their significance
7. **Conclusion**: Summary of contributions and potential future work
8. **References**: Properly formatted citations
9. **Appendices**: (If needed, beyond the 3-page limit)

## 🎬 Video Creation Guidelines

Your demonstration video should:

1. Begin with a brief introduction of team members and project title
2. Clearly show the security concept or tool in action
3. Include narration explaining what is being demonstrated
4. Highlight key technical aspects and security implications
5. End with a summary of findings or conclusions

**Technical Requirements:**
- Resolution: 720p minimum (1080p recommended)
- Length: 3-5 minutes
- Format: MP4 preferred
- Audio: Clear narration with minimal background noise

**Recording Tools:**

- [Camtasia](https://www.techsmith.com/video-editor.html) (Commercial)
- [Zoom](https://zoom.us/) (Recording feature)
- Screen recording features in Windows (Win+G) or macOS (QuickTime)

## 💡 Recommended Project Topics

### Network Security
1. **Intrusion Detection System Implementation**
   - Set up and configure an IDS (e.g., Snort, Suricata)
   - Create custom rules for specific attack patterns
   - Test effectiveness against various attack scenarios

2. **VPN Security Analysis**
   - Compare security features of different VPN protocols
   - Implement and test a secure VPN configuration
   - Demonstrate potential vulnerabilities and mitigations

3. **Wireless Network Security Assessment**
   - Analyze security of different wireless protocols
   - Demonstrate common wireless attacks and defenses
   - Implement secure wireless network configurations

### Application Security
4. **Web Application Vulnerability Assessment**
   - Identify and exploit common web vulnerabilities (OWASP Top 10)
   - Implement secure coding practices to mitigate vulnerabilities
   - Create a secure web application with proper security controls

5. **Mobile Application Security Analysis**
   - Reverse engineer a mobile application to identify vulnerabilities
   - Implement secure coding practices for mobile applications
   - Demonstrate secure authentication and data storage techniques

6. **API Security Implementation**
   - Design and implement secure API authentication
   - Demonstrate common API vulnerabilities and mitigations
   - Create a secure API gateway with proper access controls

### System Security
7. **Container Security Implementation**
   - Analyze security risks in containerized environments
   - Implement security best practices for Docker/Kubernetes
   - Demonstrate container escape vulnerabilities and mitigations

8. **Operating System Hardening**
   - Implement security hardening techniques for Windows/Linux
   - Demonstrate effectiveness against common attacks
   - Create automated hardening scripts and security baselines

9. **Secure Boot and Trusted Computing**
   - Implement and analyze secure boot mechanisms
   - Demonstrate TPM-based security features
   - Create a secure system configuration with integrity verification

### Cryptography & Authentication
10. **Multi-factor Authentication Implementation**
    - Design and implement a multi-factor authentication system
    - Compare security and usability of different MFA methods
    - Demonstrate potential bypass techniques and mitigations

11. **Blockchain Security Analysis**
    - Implement a simple blockchain with security features
    - Demonstrate potential vulnerabilities in blockchain systems
    - Analyze security implications of different consensus mechanisms

12. **Secure Communication Protocol Implementation**
    - Design and implement a secure communication protocol
    - Analyze cryptographic primitives and their security properties
    - Demonstrate secure key exchange and message encryption

### Offensive Security
13. **Penetration Testing Framework**
    - Develop a methodology for systematic penetration testing
    - Demonstrate tools and techniques for different testing phases
    - Create a reporting framework for findings and recommendations

14. **Social Engineering Toolkit**
    - Develop and demonstrate social engineering techniques
    - Analyze effectiveness of different approaches
    - Create awareness training materials for defense

15. **Red Team Infrastructure Setup**
    - Design and implement a red team infrastructure
    - Demonstrate command and control mechanisms
    - Implement OPSEC considerations and evasion techniques

### Defensive Security
16. **Security Monitoring System**
    - Implement a SIEM solution (e.g., ELK Stack, Splunk)
    - Create custom detection rules for specific threats
    - Demonstrate incident response procedures

17. **Threat Hunting Methodology**
    - Develop a systematic approach to threat hunting
    - Implement tools and techniques for proactive threat detection
    - Demonstrate hunting for specific advanced threats

18. **Security Automation Framework**
    - Design and implement security automation using tools like Ansible
    - Create playbooks for common security tasks
    - Demonstrate automated incident response procedures

## ❓ Frequently Asked Questions

**Q: Can we choose a topic not on the recommended list?**  
A: Yes, you can propose any cybersecurity topic as long as it includes a hands-on component. All topics require instructor approval.

**Q: What if we can't complete the entire project as planned?**  
A: Document the challenges you encountered, what you learned, and how you would approach the problem differently. The learning process is as important as the final result.

**Q: Can we use existing tools or must we create everything from scratch?**  
A: You can use existing tools, but you must add value through configuration, customization, integration, or analysis. Simply running a tool without significant contribution is insufficient.

**Q: How technical should our presentation be?**  
A: Your presentation should be technical enough to demonstrate your understanding but accessible to classmates who may not be familiar with your specific topic.

**Q: Can we collaborate with other teams?**  
A: Each team should work independently on their own project. However, you can share knowledge and resources as long as each team's work remains distinct.
