# Repository Purpose
This repository contains materials for the CS4910 course project. It includes several assignments (assignment1 to assignment4), project templates, sample examples, and various documentation files.

# General Setup
The repository is structured as follows:
- **README.md**: Main README file for the repository.
- **assignments1-4/**: Directories containing materials for each assignment.
- **project_templates/**: Templates for course projects.
- **sample-project-examples.md**: Examples of sample projects.
- **syllabus.md**: Course syllabus.
- **video-demo-guide.md**: Guide for video demonstrations.
