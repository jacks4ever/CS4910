# IEEE Report Template Instructions

## Getting the Template

1. Download the IEEE conference proceedings template from:
   https://www.ieee.org/conferences/publishing/templates.html

2. Select "US letter" template format for Microsoft Word

## Using the Template

1. Do not modify the template's formatting, margins, or column layout
2. Follow the structure outlined in report_template.md
3. Limit main content to 3 pages (appendices can be additional)
4. Use proper IEEE citation format

## Submission

1. Save as Word document (.docx)
2. Filename: CS4910_ProjectTitle_LastName1_LastName2.docx
3. Submit on Canvas by December 15, 2025
4. Only one team member needs to submit
