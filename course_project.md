# 🔐 CS 4910: Cybersecurity Course Project

## 📋 Project Overview

This document provides the essential guidelines for your CS 4910 course project. The project is designed to give you hands-on experience with cybersecurity concepts while developing practical skills.

## 👥 Team Structure
- Work in teams of **two students**
- Both team members must contribute equally
- Each team selects a unique cybersecurity topic

## 🔑 Key Requirements
- Project must focus on a cybersecurity topic
- Must include a hands-on, practical component
- Must demonstrate security concepts learned in class

## 📦 Required Deliverables

Your team must submit the following by **December 15, 2025**:

### 1. PowerPoint Presentation
- 10-12 slides summarizing your project
- Include: introduction, methodology, implementation, results
- Use the [presentation template outline](project_templates/presentation_outline.md) as a guide

### 2. Demo Video (3-5 minutes)
- Show your implementation in action
- Explain key technical aspects
- Highlight security implications
- See the [video creation guide](project_templates/video_creation_guide.md) for tips

### 3. Project Report
- 3-page report in IEEE conference proceedings format
- Follow the [IEEE template](https://www.ieee.org/conferences/publishing/templates.html)
- See the [report template guide](project_templates/report_template.md) for structure
- Additional content can be included in appendices (beyond the 3-page limit)

## 📅 Team Accountability Timeline

This timeline is provided **solely for team members to hold each other accountable**. It is not a submission schedule, and no check-ins or presentations to the professor are required at these milestones. The only required submission is the final project materials by December 15.

## ❓ Frequently Asked Questions

**Q: Do we need to present our project to the class?**  
A: No. You only need to submit the PowerPoint, video, and report by the deadline.

**Q: Can we choose a topic not on the recommended list?**  
A: Yes, you can propose any cybersecurity topic as long as it includes a hands-on component.

**Q: What if we can't complete the entire project as planned?**  
A: Document the challenges you encountered, what you learned, and how you would approach the problem differently.

**Q: Can we use existing tools or must we create everything from scratch?**  
A: You can use existing tools, but you must add value through configuration, customization, integration, or analysis.

**Q: How do we submit the project?**  
A: Only one team member needs to submit all three deliverables (PowerPoint, video, and report) on Canvas by the deadline.

## 📝 Submission Instructions

1. **PowerPoint**: Save as .pptx format
2. **Video**: Upload to YouTube (unlisted) or submit MP4 file
3. **Report**: Submit as Word document (.docx) following IEEE format
4. **Naming Convention**: Use format "CS4910_ProjectTitle_LastName1_LastName2" for all files
5. **Submit**: One team member uploads all files to Canvas by December 15, 2025

**Important Note**: No in-person presentations to the professor are required. The timeline provided is solely for team accountability. All evaluation will be based on the submitted materials (PowerPoint, video, and report).
