# 📄 IEEE Template Guide for CS 4910 Project Report

## 📋 Template Requirements

Your project report must follow the IEEE conference proceedings format exactly as specified. This document provides guidance on using the official IEEE templates.

## 🔗 Official IEEE Templates

**Download the official templates from:**
- **Word Template:** [IEEE Conference Template (Word)](https://www.ieee.org/content/dam/ieee-org/ieee/web/org/conferences/Conference-template-A4.docx)
- **LaTeX Template:** [IEEE Conference Template (LaTeX)](https://www.ieee.org/conferences/publishing/templates.html)

## 📝 Report Structure

### Required Sections (in order):

1. **Title** - Descriptive and specific to your project
2. **Authors** - Both team members' names and affiliations
3. **Abstract** (150-200 words) - Concise summary of your work
4. **Keywords** - 3-5 relevant terms
5. **Introduction** - Problem statement and motivation
6. **Related Work** - Literature review and background
7. **Methodology** - Your approach and implementation details
8. **Results** - Findings, data, and analysis
9. **Discussion** - Interpretation and implications
10. **Conclusion** - Summary and future work
11. **References** - IEEE citation format

### 📏 Formatting Requirements

- **Length:** Exactly 3 pages (main content)
- **Format:** Two-column IEEE conference style
- **Font:** Times New Roman, 10pt for body text
- **Margins:** As specified in IEEE template
- **Spacing:** Single-spaced with IEEE formatting
- **Figures/Tables:** Professional quality with captions
- **Citations:** IEEE reference format [1], [2], etc.

## ✅ Submission Checklist

- [ ] Used official IEEE template without modifications
- [ ] Report is exactly 3 pages (excluding references if needed)
- [ ] Both team members' names are on the report
- [ ] Project title is descriptive and specific
- [ ] All figures and tables have proper captions
- [ ] References are in IEEE format
- [ ] File named: "CS4910_ProjectReport_LastName1_LastName2.docx"
- [ ] Submitted by one team member on Canvas

## 🚫 Common Mistakes to Avoid

- **Don't modify** the template spacing or column format
- **Don't exceed** 3 pages for main content
- **Don't forget** to cite all external sources
- **Don't use** informal language or first person
- **Don't include** large code blocks (use appendices)
- **Don't submit** PDF unless specifically requested

## 🎯 Writing Tips

### Technical Writing Best Practices:
- Use clear, concise sentences
- Write in third person, passive voice
- Define all acronyms on first use
- Use present tense for your work, past tense for others'
- Include quantitative results where possible

### Figure and Table Guidelines:
- All figures/tables must be referenced in text
- Use high-quality, readable images
- Include descriptive captions
- Place close to relevant text

### Citation Guidelines:
- Cite all external sources, tools, and datasets
- Use IEEE reference format consistently
- Include DOI or URL for online sources
- Prefer peer-reviewed academic sources
