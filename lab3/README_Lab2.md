# CS 4910 Lab 2: Information Theory, Cryptography, and Security Analysis

## Overview

This lab builds upon the foundational concepts from Lab 1 and focuses on information theory, cryptographic systems, and security analysis. Students will explore entropy calculations, digital envelope systems, password security, and symmetric encryption comparisons while leveraging AI tools for enhanced learning.

## Lab Structure

### Part 1: Information Theory and Entropy Analysis (25 points)
- **Balls in Bin Analysis**: Calculate entropy for different probability distributions
- **Communication Entropy**: Analyze entropy in network communication systems
- **Security Implications**: Understand the relationship between entropy and security

### Part 2: Digital Envelope Systems and Authentication (25 points)
- **System Design**: Create digital envelopes providing confidentiality and authentication
- **Implementation**: Build working digital envelope system
- **Security Analysis**: Evaluate attack resistance and security properties

### Part 3: Password Security and Brute Force Analysis (25 points)
- **Traditional Passwords**: Analyze entropy and brute force resistance
- **CVCN Method**: Evaluate structured password generation
- **Comparative Analysis**: Compare different password generation approaches

### Part 4: Symmetric Encryption Security Analysis (15 points)
- **DES vs AES**: Compare key spaces and security properties
- **Performance Analysis**: Benchmark encryption algorithms
- **Security Evolution**: Understand cryptographic algorithm progression

### Part 5: Advanced Cryptographic Concepts (10 points)
- **Research Topics**: Explore cutting-edge cryptographic technologies
- **Security Analysis**: Evaluate emerging security paradigms
- **Future Implications**: Understand long-term security considerations
