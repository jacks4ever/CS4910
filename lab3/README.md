# CS4910 Lab 3: Ethics in Cybersecurity and Access Control Systems

## 📋 Lab Overview

This repository contains Lab Assignment 3 for CS4910: Introduction to Computer Security. This lab explores the critical intersection of ethics and cybersecurity while diving deep into access control mechanisms and database security.

## 🎯 Key Components

- 🤝 **Ethics in Cybersecurity**: Apply DFEI Ethics Principles to real-world security disclosure scenarios
- 🔐 **Access Control Models**: Analyze DAC, RBAC, and ABAC systems with practical implementations
- 📊 **Database Security**: Understand relational database security and privilege management
- 🛡️ **Security Policy Design**: Create comprehensive access control policies for complex scenarios
- 📝 **Ethical Decision Making**: Develop frameworks for ethical reasoning in cybersecurity contexts
- 📚 **Textbook Problems**: Solve problems 4.1, 4.8, 4.12, 5.3, and 5.8 from the course textbook
- 🤖 **AI-Enhanced Learning**: Leverage AI tools for ethical reasoning and policy verification
