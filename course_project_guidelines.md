# 🔐 CS 4910: Cybersecurity Course Project Guidelines

## Project Overview

This document provides essential guidelines for your CS 4910 course project. The project is designed to give you hands-on experience with cybersecurity concepts and tools while developing your research, implementation, and presentation skills.

## 👥 Team Structure
- Work in teams of **two students**
- Both team members must contribute equally
- Each team selects a unique cybersecurity topic

## 🔑 Key Requirements
- Project must focus on a cybersecurity topic
- Must include a hands-on, practical component
- Must demonstrate security concepts learned in class
- Must include both attack and defense perspectives (when applicable)

## 📋 Required Deliverables

### 1. Final Presentation
- 10-12 minute presentation to the class
- PowerPoint or similar format
- Cover project background, methodology, implementation, and findings
- Both team members must participate in presenting

### 2. Demo Video
- 3-5 minute video demonstration
- Show your implementation in action
- Explain key technical aspects
- Highlight security implications

### 3. Project Report
- 3-page report in IEEE conference proceedings format
- Follow the IEEE template: [IEEE Templates](https://www.ieee.org/conferences/publishing/templates.html)
- Additional content can be included in appendices (beyond the 3-page limit)
- Proper citations required for all external resources

## 📅 Important Dates
- **Topic Selection**: Week 4
- **Project Proposal**: Week 7
- **Final Presentation**: Week 16
- **Demo Video & Report**: Due by December 15, 2025

## 📝 Report Structure
1. **Title and Author Information**
2. **Abstract** (150-200 words)
3. **Introduction** (background, motivation, objectives)
4. **Related Work** (existing solutions/research)
5. **Methodology** (approach, tools, techniques)
6. **Implementation** (technical details)
7. **Results & Analysis** (findings, security implications)
8. **Conclusion** (summary, future work)
9. **References** (IEEE format)
10. **Appendices** (if needed, beyond the 3-page limit)

## 🎬 Video Guidelines
- Begin with team introduction and project overview
- Clearly demonstrate your implementation
- Provide narration explaining what is being shown
- Highlight security aspects
- Maintain professional quality (clear audio, visible screen)
- Export as MP4 format (720p minimum resolution)

## 💡 Project Topic Areas
Choose from these areas or propose your own (subject to instructor approval):

1. **Network Security**
   - Intrusion detection/prevention
   - Firewall implementation and testing
   - VPN security analysis
   - Network traffic analysis

2. **Application Security**
   - Web application vulnerability assessment
   - Secure coding practices
   - Mobile application security
   - API security

3. **System Security**
   - Operating system hardening
   - Container/virtualization security
   - Access control implementation
   - Privilege escalation detection/prevention

4. **Cryptography & Authentication**
   - Encryption implementation and analysis
   - Authentication system design
   - Password security
   - Blockchain applications

5. **Offensive Security**
   - Penetration testing methodology
   - Vulnerability discovery
   - Exploit development (in controlled environment)
   - Social engineering techniques

6. **Defensive Security**
   - Security monitoring implementation
   - Incident response procedures
   - Threat hunting techniques
   - Security automation
